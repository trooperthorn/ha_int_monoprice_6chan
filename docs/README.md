# Documentation index

This directory holds the rationale, protocol facts, and operational notes
that used to live in code comments. Each file owns one kind of content.

- [design.md](design.md): architecture and rationale, including the device
  hierarchy and the release trigger design.
- [protocol.md](protocol.md): RS-232 wire-format facts (frame structure,
  value ranges, command codes), with verified versus unverified rows.
- [security.md](security.md): release supply-chain controls (SBOM, build
  provenance attestation, immutable tag/release sequencing).
- [operations.md](operations.md): the test gate, the release path and its
  GitHub App, branch protection, and line endings.
- [decisions.md](decisions.md): dated decisions with the alternative rejected
  and why.
- [backlog.md](backlog.md): dated open items and TODOs.
